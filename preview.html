vuejs/core

渐进式 JavaScript 框架，用于构建现代 Web 应用。简洁的 API、优秀的性能和丰富的生态系统。

特性

  • 渐进式框架：可以根据需求逐步引入
  • Composition API：更灵活的代码组织方式
  • 性能卓越：基于 Proxy 的响应式系统
  • TypeScript 支持：提供完整的类型定义
  • 丰富的生态：Router、Pinia、Vite 等官方工具

响应式系统核心原理

Vue 3 的响应式系统基于 Proxy 实现。核心流程：

  • track() — 收集依赖
  • trigger() — 触发更新
  • effect() — 副作用注册
